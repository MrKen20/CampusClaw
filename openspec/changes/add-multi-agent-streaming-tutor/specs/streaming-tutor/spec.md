## Purpose
让 CampusClaw 教师按班级配置多个解题智能体与技能，学生在自己的持久化会话中依据该智能体绑定的资料连续追问，以可追溯的真实增量流接收回答，并可同时运行多个彼此独立的智能体会话。

## ADDED Requirements

### Requirement: 本班智能体与绑定
系统 MUST 提供本班智能体列表、新建、读取和修改；教师才能写。名称必填且班内唯一（最多64字），提示词最多2000字、空时用默认角色，enabled 控制新会话选用；绑定只能指向本班技能与材料，更新 MUST 原子完成。
#### Scenario: 权限与绑定隔离
- **WHEN** 学生写智能体或教师绑定他班资源
- **THEN** 学生 MUST 得403；越界绑定 MUST 与不存在同形404，原绑定不变
#### Scenario: 多智能体可用
- **WHEN** 教师创建两个启用的智能体，各自绑定不同配置
- **THEN** 学生 MUST 可分别新建会话；学生列表/按编号读取不得暴露停用或他班智能体，教师可管理本班停用者

### Requirement: 技能文件管理与路由
系统 MUST 支持教师编写或上传 .md/.txt 技能文件（JSON source_text 传入）；中文元数据名称、适用条件、启用必填，资料/工具可选，空行后正文必填。全文最多8000字，名称32、适用条件120、资料32、正文2000；重复或未知字段、非法启用值、非 knowledge_search 工具 MUST 400。名称班内唯一。读操作需登录，写需教师；删除同时解除绑定。候选只含本班、当前智能体绑定且启用的技能；按关键词子串匹配计分，大小写不敏感，中英文逗号/顿号/分号/竖线切分，零分不选，同分取较小id，至多一个。
#### Scenario: 解析拒绝与确定性路由
- **WHEN** 提交缺字段/重复字段/非法工具或两项技能同分
- **THEN** 非法提交 MUST 400且不写数据；同分 MUST 选较小id，未绑定/停用者不得参与

### Requirement: 私人持久化会话
会话 MUST 记录 class_id、user_id、agent_id 与时间；新建必须选择本班已启用智能体，空可用列表返回400，其余不存在/停用/他班返回同形404。会话只能本人本班读取，锁定 agent_id；智能体后来停用不影响既有会话。消息仅 user/assistant，记录正文、引用、技能、完成状态；首问前24字作标题。每轮配置与绑定重读，历史最多最近6条、每条500字，本轮只出现一次。
#### Scenario: 会话不可改绑及私人归属
- **WHEN** 消息体伪造另一个 agent_id、history 或 class_id，或读取他人的会话
- **THEN** 请求字段 MUST 不影响会话归属/历史/智能体；他人或他班与不存在 MUST 同形404
#### Scenario: 配置即时生效
- **WHEN** 教师修改提示词/解绑技能/停用技能，或停用智能体
- **THEN** 下一轮 MUST 重读配置；原会话可继续，停用智能体不能创建新会话

### Requirement: 绑定范围内检索与提示词组装
会话检索 MUST 在本班且智能体绑定材料内执行 hybrid，取前4条后按选中技能资料词筛标题，空正文丢弃；编号连续、每段最多800字。系统消息只放角色、选中技能说明及固定边界，有解题引导技能时 MUST 引导且不直接给最终答案。资料只能放用户消息，客户端 system/历史不可注入。无依据会话 MUST 仍调用模型，引用为空且不得出现[n]、不得整段固定未找到；既有 /api/ask 无依据不生成行为 MUST 保留。
#### Scenario: 无依据与未绑定资料
- **WHEN** 智能体未绑定材料或检索无命中
- **THEN** 会话 MUST 按角色作答且空引用，无伪编号；/api/ask MUST 仍回固定文案
#### Scenario: 技能启停行为
- **WHEN** 同一题先命中解题引导，再停用该技能并重复
- **THEN** 启用时 MUST 只指出思路/错误与下一步，停用后按角色直接回答；引用只能来自绑定范围

### Requirement: 真实流式输出与错误保存
系统 MUST 使用网关 stream=true 真增量输出，POST 消息携带Bearer；SSE首事件meta含status=ok/skill/citations，后续delta为新增文本，done在助手落库后含message_id。流前失败用400/401/404/409/503；流后失败用error，已发片段 MUST 持久化为partial，断连亦保留已产生片段；空正文失败不写空助手消息。无依据及无效编号 MUST 在跨片段边界过滤。Nginx禁用缓冲，每帧flush，密钥不上前端/日志/文档。
#### Scenario: 完成与中途失败
- **WHEN** 生成成功或输出若干片段后上游失败
- **THEN** 成功 MUST meta→delta多次→done且拼接正文等于数据库；失败 MUST error并保存已发正文、标记partial

### Requirement: 多智能体会话并行
界面 MUST 支持同时打开多个会话面板，独立输入/消息/引用/生成状态/AbortController，切换页面或收起面板不得串流；可停止某一会话而不影响其他。服务端不得全局串行，同一会话并发发送 MUST 409且无额外消息，不同会话 MUST 同时推进。
#### Scenario: 两个独立生成
- **WHEN** 同时向两个智能体会话发消息并停止其中一个
- **THEN** 两边 MUST 独立输出且另一流继续；刷新后可读取已存消息和各自智能体，收起不删除会话

### Requirement: 文档与接口验收
所有实际业务接口 MUST 从处理函数旁注解生成 OpenAPI，描述请求响应/错误/鉴权，提供本地 Swagger UI 可试调，Bearer形态如实为不透明token。apitest MUST 一个接口一个URL目录脚本，run_all.py一键生成不入Git的HTML报告；至少覆盖登录、检索、智能体/提示词、技能、会话和消息，核对响应与数据库及越权、并行、流式事件和持久化。
#### Scenario: 文档与报告可复现
- **WHEN** 重生成文档并运行接口测试
- **THEN** 文档 MUST 与路由一致、无密钥；测试报告 MUST 有各项结果和断言，报告被Git忽略
