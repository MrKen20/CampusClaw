## Decisions

1. `tutor_app_templates`以(class_id,app_key)为键保存user_template和version，默认模板在无覆盖行时回退。教师PUT `/api/ai-apps/{key}/template`，body包含user_template/expected_version；首次version0，冲突409。只接受本应用已声明的占位符并要求每个字段保留，限制模板展开最坏不超过500字。学生列表、预览与launch读取同一有效模板。应用页在聚焦/可见时每5秒刷新，教师草稿不被刷新覆盖；已有学生会话文本不追溯替换。
2. 取消Tutor前端TraceDetails渲染、capture_trace控件及参数。原owner-only诊断API继续供本地测试使用，默认仍不采集。没有新的教师隐私接口。
3. 从服务端seed_key识别应用，独立于名称/技能开关。阅读/写作只接纳语文类标题，概念/错题按问题中的学科线索确定范围（数学、语文、英语、科学）；无法判断则不引入库资料。排除模板公共词后要求至少两个不同内容二字词与切片重合；保守拒绝不确定材料。先按学科筛选已绑定资料ID，再检索与按正文内容过滤；没有适用绑定时跳过知识检索。适用材料在模型上下文构建前过滤。候选不等于引用，最终只保留回答中实际出现的[n]。历史响应按原问题与同样规则投影过滤，删除失效编号但不修改数据库原始回答/trace。学生前端也只显示正文用到的引用，避免生成中展示尚未采用的候选。
4. 资料新增version默认1；教师PUT JSON {title,body,version}修改当前文本，DELETE JSON {version}删除，冲突409。本班校验在Go，跨班404，学生403。新版本写服务端随机文件名，事务切换资料文件指针与知识正文，同时清理旧切片；提交失败删除新文件、原文不变；成功后下载最新版本。
5. Indexer提供每材料共享锁，编辑、删除、上传索引、重建、启动补索引共用。索引构建加锁后重新读取当前数据库正文，防止等待中的旧任务复活删除材料或覆盖新正文。编辑后重建当前正文；嵌入失败保留编辑结果并返回index_status=failed。删除在事务内清正文/切片/绑定/材料，远端向量和旧文件尽力清理；远端故障时SQL回表继续拒绝孤立点。只删除上传目录内的受控文件。
6. 对改名/删除的旧资料标题写入`material_seed_suppressions`，启动种子逻辑跳过这些标识，避免删除或改名后重生。允许教师正常上传同名新资料，不引入垃圾箱或批量删除。

## Verification

模板占位符/长度/版本、角色/班级持久化与启动同步；四应用新旧引用、技能关闭仍过滤、相关资料保留、无引用候选隐藏；资料编辑下载/检索更新、删除绑定/向量清理、同班教师与学生/跨班限制、非法/冲突不修改、种子不重生、并发旧索引不复活。前端build/tests、双角色浏览器与Swagger校验、真实网关针对性回归。保留现有未提交工作，不覆盖用户数据。
