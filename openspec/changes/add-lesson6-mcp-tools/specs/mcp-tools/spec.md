## ADDED Requirements

### Requirement: 同仓可调用的教学MCP服务
系统 MUST 在mcp-server/提供独立Compose服务，只暴露工具能力、HTTP JSON-RPC及health，至少两个只给提示的工具，令牌缺失启动失败。
#### Scenario: 协议与认证
- **WHEN** 访问health，或分别以正确/缺失/错误Bearer调用initialize、tools/list、tools/call
- **THEN** health正常，正确令牌可发现formula_hint与unit_convert并取文本，无效令牌401；非法JSON/方法/参数有可读JSON-RPC错误，同一id响应对应请求；initialized通知202，GET /mcp为405
- **AND** 工具不输出完整题目的最终数值答案，MCP端口不映射宿主，密钥不入镜像或前端

### Requirement: 教师班级内管理与令牌边界
系统 MUST 服务端强制教师角色、会话班级与精确网络白名单，登记令牌加密，列表/详情/错误/日志仅有has_auth而无原文。
#### Scenario: CRUD与隔离
- **WHEN** 本班教师登记修改删除，学生调用管理API，或另一班教师按id访问
- **THEN** 本班操作正确且同名重复400，修改留空令牌保留；学生403，跨班与缺失同形404，无越权写入；重启登记仍在，删除保留历史审计
#### Scenario: 安全连接与发现
- **WHEN** 教师连续两次连接或断开，或握手/发现/schema校验失败
- **THEN** 成功整体替换工具快照不翻倍；断开或失败connected=false且缓存清空，给出安全可读原因；未经白名单的地址、URL凭据/查询、重定向均被拒

### Requirement: 工具审阅与技能绑定
系统 MUST 支持knowledge_search和严格小写tool@server，保存时校验同班已连接已发现且工具只读、非外发、已审阅批准，说明变更撤回批准并留记录。
#### Scenario: 保存前校验与说明确认
- **WHEN** 保存有效引用、错误格式/大小写/缺失/他班/断开/未批准/写入工具引用，或重连改变说明
- **THEN** 有效引用保存，其余400且不修改原技能；教师可见完整说明与schema后批准，批准须携带当前指纹；说明变更需重新批准，旧指纹409

### Requirement: 模型驱动且受限的多轮工具编排
系统 MUST 从发现结果生成模型tools声明；只把命中技能绑定且授权的工具作为候选，模型决定工具与参数，宿主按同一JSON Schema验证、逐次复核并执行，结果在数据位回传。
#### Scenario: 两轮调用与真实流
- **WHEN** 模型先后提出两轮合法调用
- **THEN** 实际请求自建远端服务，逐轮工具消息回传，meta.tool_calls先于首个delta，最终仍为课程网关stream=true真实增量；不同学生会话互不串扰
#### Scenario: 局部失败与拒绝
- **WHEN** 工具断开/删除/越权/参数错误/超时/自报错误/异常格式，或工具文本含已知注入句式或令牌
- **THEN** 返回ok/error/denied的真实状态，拒绝不发远端动作，错误安全脱敏并作为数据回传；可归属服务器时写审计；检索与最终回答继续，工具文本永不拼进system
#### Scenario: 三类上限与取消
- **WHEN** 达轮数/每问累计/会话累计/时间上限，或学生停止生成
- **THEN** 不再执行新工具，超限用已有信息生成回答；取消停止当前请求，已发内容保留partial，不能影响其他会话；无工具技能沿用第5课主路径

### Requirement: 可观察的界面与交付
系统 MUST 提供教师MCP管理/批准/本班审计与学生调用状态，刷新可回放；文档/接口测试与实际实现一致。
#### Scenario: 记录与历史
- **WHEN** 分别触发成功/被拒/失败后教师查看审计并刷新学生会话
- **THEN** 审计按时间倒序，含引用/服务器名/用户/会话/提问/轮次/状态/摘要/时间，仅本班；历史调用状态可恢复，无调用时不显示空工具栏
#### Scenario: 浏览器与接口验证
- **WHEN** 使用桌面/390px和深浅色操作教师MCP与学生会话，或从登录页进入Swagger
- **THEN** 操作清晰、无整体横向溢出，connect/tools/技能保存接口可试调，apitest含权限/DB/真实工具闭环并生成忽略Git的HTML报告；真实同伴互验保留待完成
