## Why

个人项目验收需要可辨识的多个 AI 应用、对应模板、标准 SKILL.md 上传，以及可复核的 LLM 请求证据。现有检索、多会话与 MCP 链路可复用，但通用聊天配置不足以清楚展示这些能力。

## What Changes

- 内置概念讲解、阅读分析、写作指导、错题复盘四个应用，各有任务表单、提示词模板与技能；启动生成可编辑提问并进入独立流式会话。
- 教师可查看并将应用的角色模板应用于智能体，继续使用已有本班技能/资料绑定配置。
- 接受标准 front matter 的 SKILL.md 单文件和含 SKILL.md 的 ZIP；保留现有 .md/.txt 格式。ZIP 内资源仅存为受限文本附件，不执行脚本、不自动全部注入模型。
- 可选开启本轮 LLM 调用详情，记录实际请求体及响应（包括工具规划与最终 SSE），只供会话所有者查看；不记录鉴权头和密钥。
- 更新 Swagger 并验证五项数据流问题。

## Capabilities

### New Capabilities
- `acceptance-apps`: 多应用、模板、标准技能导入与调用可观测性。

### Modified Capabilities
无。复用已实现的班级检索、MCP 授权和会话隔离，长期规约本轮不回写。

## Impact

Go tutor/retrieval、MySQL 增量字段、React 应用入口与教师编辑器、API 文档和验收脚本。无需增加外部运行时。

## Non-goals

不实现图片识别、作业布置/提交/评分/改分完整流程、消息队列、个人笔记、任意代码执行、全部资源自动加载、跨班共享、远端 Git 更新或 PDF 报告。本轮只修改本地工作区，不创建 Git 提交（遵从用户暂不更新仓库的指示）。
